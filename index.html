LLM TRIAGE CLASSIFICATION FOR SOUTH ASIAN LANGUAGES

Model Agnostic Uncertainty Estimation for LLM Triage Classification for South Asian languages

- Engineered a 2S (semantic similarity) confidence score to quantify model certainty on critical emergency predictions across datasets. Wanted to clarify if the model was confident in its answers before proceeding.

- Evaluated cross-lingual consistency using BERTScore precision and recall metrics across identical prompts in multiple languages. Knowing how precise the model is allows me to factor out language barriers.

- Found systemic model overconfidence, identifying the LLM produced a >75% confidence score on nearly all 5,000 cases, regardless of input language.

NEMOTRON AUDITOR

SteelHacks XIII Contestant

- Built a safety gate that audits LLM-generated medical advice. An LLM extracts findings, then a deterministic Python policy layer converts findings into a show/withhold decision, so every withheld answer names the rule that blocked it.

- Evaluated on a 41-case labeled set built by injecting known flaws into correct drafts, making ground truth free. The gate caught 26/31 unsafe drafts while shipping 10/10 safe ones. The model’s own risk score alone caught only 17/31 at identical coverage.

- A same-prompt GPT-4o-mini judge caught 30/31 but shipped only 2/10 safe answers - so recall alone can’t distinguish a usable gate from one that blocks the product.
